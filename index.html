📐 ТЗ / Архитектура Riskgift (Fullstack)

Frontend (React/Vue - данный прототип на чистом JS): Мобильная адаптация, экраны Welcome / Store, горизонтальная рулетка (cubic-bezier), честная математика 70/20/10. Инвентарь + баланс в localStorage.

Backend & Webhook логика: При отправке Telegram Gift на @Gift_Storage_Bot, бот ловит message, парсит gift type, конвертирует в TON (0.14/0.23/0.41) и через API начисляет на баланс user_id. Хранилище: PostgreSQL (таблица users: user_id, ton_balance, inventory_json). В прототипе симуляция кнопками.

Вывод: Пользователь запрашивает вывод TON → система проверяет баланс, отправляет транзакцию TON. Вывод подарков: бот пересылает gift обратно в ЛС пользователя.

База данных: users (id, tg_id, ton_balance, gifts JSONB [bear, rose, cake, nft_array]), case_logs.

Математическая модель: 70% TON (диапазон 10-50% от стоимости кейса), 20% обычные подарки (равновероятно мишка/роза/торт), 10% NFT Gifts.

Интеграция TON: Wallet Connect / Tonkeeper для пополнения, в демо симуляция.

✅ Прототип полностью рабочий, все механики реализованы локально.
